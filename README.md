# Leonard der Superheld

## Folge: Leonard erwacht
- `Leonard-erwacht/Leonard_erwacht_FINAL.mp4`: 39 s, 640x360, 24 fps. Vier KI-Clips (Aufwachen, Schrank, Verwandlung, Spiegel) mit Überblendungen, Ton-Crossfades und eingemischten Soundeffekten.
- `Leonard-erwacht/werkzeuge/sfx.py`: erzeugt die Soundeffekte (Wecker, Vögel, Spannungs-Puls, Whoosh, Wirbel, Riser, Knall, Glockenspiel, Spiegel-Stinger, Finale) als WAV.
- `Leonard-erwacht/werkzeuge/match.py`: findet die ähnlichsten Bilder an den Schnittstellen zweier Clips.
- `Leonard-erwacht/werkzeuge/zusammensetzen.sh`: setzt Clips und Effekt-Spur zum fertigen Film zusammen.

- `Teaser/Leonard_Teaser_16x9.mp4`: Hollywood-Teaser (22,9 s), gebaut mit `Teaser/build.py` und `Teaser/text/render.js` (Motion-Skill social-teaser-video).

**Wiedereinstieg:** zuerst [memory.md](memory.md) lesen. Dort steht alles zum Weitermachen (Clips, Übergänge, Effekte, Neubau Schritt für Schritt, neue Folge anlegen).
